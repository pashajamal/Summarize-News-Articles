# AI News Summarizer & Sentiment Analyzer

A desktop GUI application built in Python that automatically scrapes online news articles from a URL, extracts metadata, generates concise summaries, and analyzes emotional sentiment.

## Features
* **Automated Scraping:** Downloads and parses web articles using `newspaper3k`.
* **NLP Summarization:** Generates quick text summaries using natural language processing.
* **Sentiment Analysis:** Calculates article polarity (Positive, Negative, Neutral) using `TextBlob`.
* **User Interface:** Clean, lightweight user dashboard built entirely using `Tkinter`.

## Tech Stack
* Python 3
* Tkinter (GUI Framework)
* Newspaper3k (Web Scraping)
* NLTK & TextBlob (Natural Language Processing)
